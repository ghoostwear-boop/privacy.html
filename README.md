POLÍTICA DE PRIVACIDAD DE CLIPPER

Última actualización: 27 de agosto de 2026

CLIPPER es un bot desarrollado por SOYMONT4NA para gestionar
solicitudes del rol Clipper dentro de servidores de Discord.

1. INFORMACIÓN QUE PUEDE RECOPILARSE

Cuando un usuario utiliza el sistema de solicitudes de CLIPPER,
puede proporcionar:

- Nombre de usuario de Discord.
- ID de usuario de Discord.
- Plataforma donde publicará clips.
- Enlaces a ejemplos de clips.
- Cantidad de clips que puede crear por semana.
- Motivo de la solicitud.

2. PARA QUÉ SE UTILIZA LA INFORMACIÓN

La información proporcionada se utiliza exclusivamente para:

- Revisar solicitudes de Clipper.
- Permitir que el Staff tome una decisión.
- Registrar la aprobación o rechazo de una solicitud.
- Gestionar el rol Clipper.
- Mantener un historial interno relacionado con las solicitudes.

3. QUIÉN PUEDE VER LA INFORMACIÓN

Las solicitudes están destinadas al equipo de Staff autorizado
del servidor correspondiente.

La información de las solicitudes no está destinada a hacerse
pública.

4. CONSERVACIÓN DE DATOS

La información puede conservarse mientras sea necesaria para
gestionar las solicitudes y el funcionamiento del sistema.

5. SEGURIDAD

Se toman medidas razonables para proteger la información
almacenada por el sistema.

6. SERVICIOS DE TERCEROS

CLIPPER funciona mediante la plataforma Discord y utiliza los
servicios proporcionados por Discord para interactuar con los
usuarios y servidores.

El uso de Discord también está sujeto a las políticas de
privacidad y términos de Discord.

7. CONTACTO

Para preguntas relacionadas con la privacidad de CLIPPER,
contacta al equipo de Staff del servidor correspondiente.

8. CAMBIOS

Esta Política de Privacidad puede actualizarse cuando sea
necesario para reflejar cambios en CLIPPER o en sus funciones.

9. ACEPTACIÓN

Al utilizar CLIPPER, aceptas esta Política de Privacidad.
